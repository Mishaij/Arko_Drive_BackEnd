Driving School Platform

A modern web platform for a driving school built with **Django**.

The platform allows students to study driving theory, learn road signs, take practice tests, view their results, and learn more about the driving school.

All educational content can be managed through the **Django Admin Panel**. Administrators can add, edit, and delete road signs, questions, tests, categories, and other content without changing the source code.



Features

Student Features

- Learn driving theory
- Study road signs
- Take theory tests
- Practice individual questions
- View test results
- Review incorrect answers
- Retake tests
- Learn about the driving school
- Responsive design for desktop and mobile devices

Road Signs

Students can browse road signs and learn:

- Sign image
- Sign name
- Description
- Category
- Meaning
- Traffic rules related to the sign

Road signs can be added, edited, or removed through the Django Admin Panel.

Theory Tests

The platform provides interactive driving theory tests.

Each test can contain:

- Questions
- Multiple answer options
- Correct answers
- Explanations
- Categories
- Configurable number of questions

After completing a test, the user can view their result and review their answers.

Admin Panel

The website uses the built-in Django Admin Panel** for content management.

Administrators can manage:

- Road signs
- Road sign categories
- Questions
- Answer options
- Tests
- Theory categories
- Theory materials
- Driving school information
- Users
- Test results

The administrator can update the website content directly from the admin panel without modifying the source code.
